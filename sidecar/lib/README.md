# TwsApi.jar

This directory should contain the official IBKR TWS API Java client library.

## Download Instructions

1. Go to https://interactivebrokers.github.io
2. Click "TWS API" download link (latest stable, currently 10.30+)
3. Extract the archive
4. Copy `TwsApi/source/JavaClient/TwsApi.jar` to this directory

The file should be named exactly `TwsApi.jar`.

This JAR is NOT available on Maven Central — it must be downloaded manually from IBKR.
